oxsv processes your 8 GB CSV in 0.2 seconds. Built entirely in x86-64 assembly with AVX2 SIMD
instructions, it scans 32 bytes per clock cycle, memory-maps files so RAM usage stays in single-digit
megabytes, and produces a 27 KB binary — 178x smaller than xsv.

## Why oxsv?

<CardGroup cols={2}>
  <Card title="Up to 76x faster" icon="bolt">
    AVX2 scans delimiters 32 bytes at a time, saturating DDR4-3200 memory bandwidth at ~30 GB/s.
  </Card>
  <Card title="Tiny footprint" icon="feather">
    27 KB stripped binary. No runtime, no allocator, no GC. Smaller than most favicons.
  </Card>
  <Card title="Works on huge files" icon="database">
    mmap keeps RAM usage in single-digit megabytes regardless of file size. A 64 GB CSV on a 4 GB machine works fine.
  </Card>
  <Card title="UTF-8 native" icon="language">
    SIMD scans for ASCII delimiters that never appear inside UTF-8 multibyte sequences. Japanese, emoji — it just works.
  </Card>
</CardGroup>

## Get started

<Steps>
  <Step title="Install dependencies">
    Install `nasm` and `gcc` on a Linux x86-64 system.
  </Step>
  <Step title="Build and install">
    ```bash
    make && sudo make install
    ```
    The binary installs to `/usr/local/bin/oxsv`.
  </Step>
  <Step title="Run your first command">
    ```bash
    oxsv count huge.csv
    oxsv headers huge.csv
    oxsv head -n 5 huge.csv
    ```
  </Step>
  <Step title="Index for instant random access">
    ```bash
    oxsv index huge.csv
    oxsv slice -i 5000000 -l 100 huge.csv   # O(1) with index
    ```
  </Step>
</Steps>
