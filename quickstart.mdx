title: "Quickstart"
description: "Get oxsv working in minutes. Inspect headers, filter rows, and build an index for instant random access on large CSV files."
---

This guide gets you from zero to processing a real CSV file in a few minutes.

<Steps>
  <Step title="Install oxsv">
    Follow the [installation guide](/installation) to build and install oxsv. Once complete, verify it is available:

    ```bash
    oxsv -v
    ```
  </Step>
  <Step title="Inspect a CSV file">
    Before processing a file, check how many rows it has and what columns are available.

    ```bash
    oxsv headers data.csv
    ```

    ```text
    1	id
    2	name
    3	email
    4	status
    ```

    ```bash
    oxsv count data.csv
    ```

    ```text
    42
    ```

    `count` returns the number of data rows, excluding the header.
  </Step>
  <Step title="View the first rows">
    Print the first 10 rows to get a feel for the data:

    ```bash
    oxsv head -n 10 data.csv
    ```

    ```text
    id,name,email,status
    1,alice,alice@example.com,active
    2,bob,bob@example.com,inactive
    3,carol,carol@example.com,active
    ```

    Omit `-n` to use the default of 10 rows.
  </Step>
  <Step title="Filter rows">
    Use `search` to keep only rows where a column matches a value. By default, oxsv uses exact match.

    ```bash
    oxsv search -s status active data.csv
    ```

    This prints all rows where the `status` column is exactly `active`, including the header row.

    For a substring match, add `--sub`:

    ```bash
    oxsv search -s name --sub ali data.csv
    ```

    UTF-8 works without any configuration:

    ```bash
    oxsv search -s name "田中" data.csv
    ```
  </Step>
  <Step title="Build an index for fast random access">
    For large files, build an index once so that `slice` and `tail` become O(1):

    ```bash
    oxsv index data.csv
    ```

    This creates `data.csv.idx` in the same directory. With the index in place, jump directly to any row:

    ```bash
    oxsv slice -i 1000000 -l 10 data.csv
    ```

    `-i` is the 0-based starting row index. `-l` is the number of rows to return. Without an index, `slice` streams through the file; with an index, it seeks directly to the byte offset.

    If the source file changes, the stale index is silently ignored and oxsv falls back to streaming.
  </Step>
</Steps>
